## Context

A new project starts by stamping the bundled templates into a fresh (private) consumer
repo — the `matctl new` move. `steward new` does the raw stamp (placeholders intact);
`/bootstrap` wraps it with an interview.

## Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | Templates ship as package-data; `new` copies them out | One wheel holds engine + scaffolding |
| 2 | `.tmpl` suffix stripped on stamp | `CLAUDE.md.tmpl` → `CLAUDE.md`, etc. |
| 3 | `new` initializes the ledger after stamping | The project is immediately drivable |

## Requirement

`steward new <dir>` stamps the full template tree (CLAUDE.md, `.claude/`, REQ scaffolding,
`.devsteward/config.yaml`), strips `.tmpl`, and initializes `.devsteward/state.yaml`.
