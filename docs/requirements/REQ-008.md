## Context

Unattended runs must survive quota limits gracefully. The machinery is lifted and
generalized from the proven `run_batch*.py`: route `claude` through `cswap` when present
(two-account, `--use N` pinning, adaptive gate), and degrade to plain single-account when
`cswap` is absent — never a hard fail.

## Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | `AccountProvider` seam: `precheck()` + `claude_argv()` | Quota policy stays out of the core loop |
| 2 | Missing `cswap` ⇒ proceed without quota check, logged | Degradation, not failure |
| 3 | `--use N` pins an account index | Ported behaviour from `run_batch` |

## Requirement

`CswapAccountProvider` builds the argv prefix and runs a non-fatal precheck;
`SingleAccountProvider` is the plain fallback. `steward run --use N` pins an account.
