## Context

The cognitive work lives in three skills the engine orchestrates: `/intake` (interview an
idea into a draft REQ), `/advance` (one Design/Build/Land checkpoint), `/bootstrap`
(bring a new project to life). All three honour park-and-surface when unattended.

## Decisions

| # | Decision | Rationale |
|---|----------|-----------|
| 1 | Skills ship as `templates/.claude/skills/*/SKILL.md` | Stamped into every consumer |
| 2 | Each SKILL.md has name+description frontmatter | Discoverable by Claude Code |
| 3 | All three document the `DEVSTEWARD_UNATTENDED=1` park rule | One consistent fork contract |

## Requirement

The three skills are bundled, each with valid frontmatter and the park-and-surface
contract described. The REQ profile invokes `/advance`.

